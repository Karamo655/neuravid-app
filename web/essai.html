Ouvrir NEURAVID
Ce qu'il faut essayer
  1. « Créer mon compte » avec son courriel (le code arrive par courriel), puis protéger le compte avec l'empreinte, dans le navigateur Chrome du téléphone.
  2. Fermer NEURAVID, le rouvrir et se reconnecter.
  3. Filmer et publier une courte vidéo avec La Forge.
  4. Lancer un court direct, puis le regarder depuis un second téléphone branché lui aussi.
  5. Noter tout ce qui bloque (capture d'écran + heure).

En revenant au site normal, la session d'essai est fermée sur ce téléphone.
